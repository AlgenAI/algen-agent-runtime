# Runtime brand assets

| Asset | Background | Intended use |
| --- | --- | --- |
| `logo-light.svg` | Transparent | Wordmark on a light surface |
| `logo-dark.svg` | Transparent | Wordmark on a dark surface |
| `logo-light-background.svg` | Included light panel | Portable light presentation |
| `logo-dark-background.svg` | Included dark panel | Portable dark presentation |
| `banner-light.svg` | Included | README and social header on light themes |
| `banner-dark.svg` | Included | README and social header on dark themes |

Keep the logo aspect ratio and accessible title/description. Do not recolor individual nodes or
remove the connections: they express Runtime's governed execution graph.

Colors follow the Algen palette used by `algen.ai` and Agent Studio: gold gradients
(`#F3D98B` → `#D4A017` → `#B8860B`), warm charcoal (`#0C0C0B` → `#2A2418`), ivory
surfaces (`#FDFCF9` → `#F4EFE3`), and accessible ink or ivory text for the selected background.
