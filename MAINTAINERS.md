# Maintainers

The current Algen Agent Runtime maintainer is:

| Maintainer | Responsibilities |
| --- | --- |
| [@saurav-samantray](https://github.com/saurav-samantray) | Project stewardship, reviews, releases, and private security triage |

Maintainers are expected to enforce the contribution, security, compatibility, and release policies in this repository. New maintainers are nominated based on sustained, trusted contributions and documented through a reviewed update to this file, `GOVERNANCE.md`, and `.github/CODEOWNERS`.

Security reports must use the private channel in [SECURITY.md](SECURITY.md), not a maintainer's personal contact details.
