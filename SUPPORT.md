# Support

Use GitHub Issues for reproducible defects and focused feature requests. Use
GitHub Discussions, when enabled, for usage questions and design exploration.
Security vulnerabilities belong only in the private channel documented in
[SECURITY.md](SECURITY.md).

The `0.x` series is early-stage software. Community support is best effort;
there is no guaranteed response time, hosted-service SLA, or production support
commitment unless covered by a separate written agreement.
